# 🏓 Retro Pong C++ & Raylib

Recreación del clásico juego Pong en C++ usando la librería gráfica Raylib. Proyecto ligero, rápido y modular enfocado en físicas fluidas, gráficos retro y alto rendimiento. Ideal como referencia para aprender desarrollo de videojuegos en 2D.

---

## 🚀 Características

* **Jugabilidad Clásica:** Partidas de uno contra uno o contra la IA con mecánicas de rebote dinámicas.
* **Alto Rendimiento:** Desarrollado en C++ puro para garantizar estabilidad y consumo mínimo de recursos.
* **Interfaz Limpia:** Gráficos minimalistas y retro gracias al renderizado 2D de Raylib.
* **Código Modular:** Estructura organizada y fácil de entender.

---

## 🛠️ Tecnologías y Librerías

* **Lenguaje:** C++
* **Librería Gráfica:** [Raylib](https://www.raylib.com/)
* **Sistema de Build:** CMake / Makefile

---

## 📦 Instalación y Ejecución

### 1. Clonar el repositorio
```bash
git clone https://github.com/tu-usuario/nombre-del-repo.git
cd nombre-del-repo
```

### 2. Compilación (Ejemplo con g++)
```bash
g++ main.cpp -o pong -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
./pong
```
